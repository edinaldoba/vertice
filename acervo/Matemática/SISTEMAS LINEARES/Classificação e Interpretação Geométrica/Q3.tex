Dado o sistema $\left\{ \begin{array}{l}
x+y=4\\
-2x+3y=-3
\end{array} \right.$. Classifique as afirmações com Verdadeiro (V) ou Falso (F).
\begin{enumerate}[(\quad)]
\item O sistema possui solução única (SPD) que é o par $(3,1)$.
\item O sistema possui solução única (SPD) que é o par $(1,3)$.
\item O sistema possui infinitas soluções (SPI).
\item O sistema é impossível.
\item Os coeficientes lineares das equações são $4$ e $-1$.
\item Na interpretação geométrica temos duas retas paralelas
\item Na interpretação geométrica temos duas retas concorrentes
\end{enumerate}
Agora, assinale a alternativa que contém a classificação correta das respectivas afirmações.
